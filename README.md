# Bhandara Invitation Website
Static site, no build step. Edit date/time, program, venue and phone in the CONFIG block at the top of script.js.
Deploy: vercel.com/new -> drag & drop this folder (or `npx vercel --prod`).

## Music
A music button (bottom-left) plays a soft built-in "Om" chant on a loop. To use your own recording instead, put an MP3 named `music.mp3` in this folder (next to index.html) and redeploy. Keep it under ~5 MB and use audio you have rights to.
